This material teaches how to work with a coding agent: an AI model that can read your files, run code, and show
evidence. It is organised as two parallel tracks over the same content, so you can start with whichever suits you
and hop to the other at any time.

- **Concept track:** the ideas, in depth, each with short links to a live demonstration.
- **Demo track:** one worked example, step by step, each step with the background you need to follow it.

Each demo step has a general part (reusable on your own data) and a clearly labelled **Workshop example**
using the supplied dataset. Switch the scenario tab if you are working from a different dataset. The choice is
remembered across pages.
