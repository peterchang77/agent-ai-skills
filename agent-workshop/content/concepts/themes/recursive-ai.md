Many good habits are the same move: **ask the agent to help with the work around the work.**

| Use the agent to… | Where it appears |
|---|---|
| Draft a plan and list the open questions | [Scoping work](concept:scoping-work) |
| Write and trim its own instructions | [Memory](concept:memory), [Steering](concept:steering) |
| Review another session's work with fresh context | [Verification](concept:verification) |
| Turn a finished task into a reusable script or skill | [Tools](concept:tools) |
| Install and record its own dependencies | [Environment](concept:environment) |
| Write commit messages and explain diffs | [Version control](concept:version-control) |

Review whatever it produces. The recursion improves your workflow only if you remain the decision-maker.
