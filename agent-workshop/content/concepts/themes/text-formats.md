An agent acts through text, so text-based formats are the ones it handles best.

| Prefer | Over | Because |
|---|---|---|
| CSV | Excel | No hidden structure to lose |
| Markdown | Word | Easy to read, diff, and convert |
| LaTeX | PDF | The source can be edited and recompiled |
| A website | PowerPoint | Text source, shareable, can hold charts |

Convert at the edges: work in text, then convert to what a collaborator needs at the end. See [Inputs](concept:inputs),
[Outputs](concept:outputs), and [What code makes possible](concept:what-code-can-do).
