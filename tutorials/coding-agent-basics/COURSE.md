# Course Guide

## The central idea

A coding agent is a practical bridge between a request and computer work. You describe a goal and constraints; the agent can inspect materials, write or run code, use available tools, create outputs, and check results. Code is useful here because it can express many digital tasks precisely and repeatably.

That does not make an agent all-powerful. It needs access to the relevant files and services, suitable tools, clear instructions, and a way to verify the result. It should ask before consequential actions.

## Learning model

Each module uses a small loop:

1. **Explain** one idea.
2. **Predict** what should happen.
3. **Do** one safe action.
4. **Inspect** evidence.
5. **Reflect** on the learner's work.
6. **Record** an important fact or artifact.

Static readers can answer prompts privately and inspect sample materials. Interactive learners complete the same steps with an agent, one short turn at a time.

## Suggested routes

- **Foundation:** new to agents or technical vocabulary. Complete every module with the sample project.
- **Practitioner:** familiar with AI chat; focus on bounded requests, checks, reusable knowledge, and the capstone.
- **Technical transfer:** comfortable with code or data work; move quickly through definitions, but complete context, skill, and model-selection exercises.
- **Goal-first:** pick a safe work-shaped capstone early; learn each concept immediately before using it.

## Completion evidence

By the end, retain:

- a bounded task request;
- a source-preserving output and validation note;
- a short `AGENTS.md` or equivalent operating-instructions file;
- a small reusable skill outline;
- a learner progress record and handoff;
- a reasoned model-selection decision.

## Glossary

- **Model / LLM:** the language-and-reasoning engine.
- **Provider:** the service that supplies authenticated access to a model.
- **Interactive chat:** a text-first conversation, usually limited to supplied content and its built-in capabilities.
- **Coding agent:** a model paired with an action loop, workspace, and tools such as file access or code execution.
- **Tool:** a concrete action the agent can use, such as reading a file or running a script.
- **Context:** the information available to the model during a conversation; its working memory.
- **Context window:** the finite capacity of that working memory.
- **Compaction:** a summary of older conversation material that frees working memory but may omit detail.
- **`AGENTS.md`:** a project instruction file supported by many agent harnesses.
- **Skill:** a reusable package of focused instructions and optional references, templates, scripts, or tools.

## Static reading sequence

Read modules in numeric order. Use the sample files when a module asks you to inspect, create, or compare something. Open links locally in a Markdown renderer or browser-based repository viewer.
