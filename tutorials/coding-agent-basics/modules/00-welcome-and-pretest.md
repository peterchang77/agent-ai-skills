# Welcome and Route Selection

## In brief

This course teaches practical habits, not programming syntax. You will learn to direct a coding agent safely, inspect its work, and preserve useful knowledge in files.

Choose sample files first unless you are authorized to use a copy of real work. The course never requires publishing, sending, deleting, or changing source files.

## Choose your goal

Write one sentence:

> I want a coding agent to help me ___, while making sure ___ does not happen.

Examples: “prepare a monthly report while keeping raw exports unchanged”; “summarize meeting notes while I approve every message before it is sent.”

## Quick diagnostic

Answer briefly. There is no score; your answers choose examples and pace.

1. What type of work do you want help with: documents, spreadsheets, data, research, software, or another task?
2. In your own words, what is the difference between a language model and a coding agent?
3. Which is safer when cleaning an important spreadsheet: edit the original, or make a derived copy and record changes? Why?
4. Optional practice: ask an agent to list files in a workspace without changing anything. What evidence did it use?

## Pick an initial route

- **Foundation:** use if the vocabulary or tools are new.
- **Practitioner:** use if you know AI chat but want dependable work habits.
- **Technical transfer:** use if you already work with code, data, or automation.
- **Goal-first:** use if you have a clear workflow to improve now.

Routes are adjustable. They change depth, not the course's core outcomes.

## Record

Create `.tutorial/learner-profile.md` and `.tutorial/progress.md` from the templates. Record your goal, route, preferred pace, and any access limits. This is your durable course record; the conversation is not.

## Checkpoint

You can continue when you have a one-sentence goal, a safe practice choice, and an initial route.
