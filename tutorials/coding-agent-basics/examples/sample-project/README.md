# Monthly Reporting Practice Project

A safe fixture for the Coding Agent Basics tutorial. All values are fictional.

## Use

- Read only from `data/raw/`.
- Write generated files under `output/`.
- Do not treat this example as a production reporting system.
- Follow [AGENTS.md](AGENTS.md) and read the notes before making metric assumptions.

## Suggested first request

See [`../request-examples/clean-csv-request.md`](../request-examples/clean-csv-request.md) for a capable broad request. Ask the agent to inspect the project, propose a plan and tool rationale, and surface only decisions that materially need your input before it creates a report.
