# Project Instructions

## Purpose

Practice creating a safe, inspectable monthly reporting workflow with fictional data.

## Working rules

- Never modify files in `data/raw/`.
- Write generated files only in `output/`.
- Read `notes/reporting-rules.md` and `notes/metric-definitions.md` before calculating metrics.
- Flag ambiguous, duplicate, or invalid-looking records; do not silently remove them.
- Do not publish, send, or connect external services.

## Paths

- Sources: `data/raw/`
- Outputs: `output/`
- Knowledge and decisions: `notes/`
- Reusable workflow: `.agents/skills/monthly-report/`

## Before finishing

- Confirm source files remain unchanged.
- Report input/output row counts and exceptions.
- Save a validation note with assumptions and unresolved questions.
