# Execution Brief Template

Use this after clarification, but keep it proportional. For a small task, use a short paragraph or three bullets. Do not make the user complete a form.

```md
## Proposed work

- **Outcome:**
- **Audience or practical use:**
- **Available material:**
- **Protected boundary:**
- **Recommended approach:**
- **Existing tools or project resources to reuse:**
- **Expected outputs:**
- **Evidence and checks:**
- **Assumptions:**
- **Decisions or approvals still needed:**
- **First safe step:**
```

Omit fields with no bearing on the request. State the recommendation and the smallest safe first action. For consequential work, end with a direct approval question.

Example:

```md
## Proposed work

- **Outcome:** Draft a manager-facing report from the approved survey export.
- **Protected boundary:** Preserve the source; flag ambiguous records; do not send or publish the report.
- **Recommended approach:** Inspect project rules and existing checks, create a derived report, and separate confirmed findings from review-needed exceptions.
- **Evidence and checks:** Input count, exceptions, output path, and the available validation result.
- **First safe step:** Inspect the project and source files without changing anything.
```
