# Baseline workshop tools

These helpers reduce environment friction. They are not solutions to the exercises.

- [`preflight.sh`](preflight.sh) checks basic command availability and required LLM environment-variable names without printing secret values.

The instructor/cloud image supplies any data-client package, approved endpoint configuration, and prepared data/download route. Do not add a finished discovery CLI, cohort builder, extraction runner, annotation tool, model pipeline, or report generator here; those are the intended agent-created artifacts.
